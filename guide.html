MOUSE COMBO · 1.5.3

安装与风险声明

版本 1.5.3 · 安装版 · 请在使用前完整阅读

安装前必读: 本程序会模拟真实的鼠标点击和键盘按键，并安装全局键盘/鼠标钩子。它可能在真实程序中造成误操作、数据丢失、账号处罚、平台规则冲突或法律风险。请先在安全环境测试，并自行确认使用场景合法合规。

1. 运行要求

  • Windows 10 / Windows 11，64 位。
  • 使用安装包时不需要安装 Python，也不需要联网。
  • 软件界面支持中文 / 日本語 / English，可在右上角语言菜单切换；切换后自动重启并保留当前宏。
  • 安装版启动后会从 GitHub Releases 检查更新，默认静默安装；可在设置页关闭自动更新。
  • 设置页支持跟随系统 / 浅色 / 深色主题、内置字体与系统字体、8–12 pt 字号、字体颜色、语言和更新选项。
  • 若目标程序以管理员权限运行，本工具通常也需要以管理员权限运行；这不会绕过目标程序的全部安全限制。

2. 安装步骤

  1. 从可信来源获取 MouseCombo-Setup-1.5.3.exe，运行安装程序。
  2. 在安装程序中完整阅读本说明与风险声明；选择“我接受”继续，选择“我不同意”退出安装。
  3. 选择安装位置和开始菜单文件夹；桌面快捷方式可选。默认安装到 %LOCALAPPDATA%\Programs\MouseCombo。
  4. 安装完成后，从开始菜单或桌面快捷方式启动。
  5. 首次启动后设置开关键（支持鼠标侧键 4/5）和触发方式，先用安全的单步宏测试停止方式。
  6. 在左侧“宏库”填写名称和分类，点击“保存”；单击列表中的宏即可切换，不需要额外窗口。
  7. 若目标程序以管理员权限运行，请也以管理员权限启动 Mouse Combo。

在 Windows“设置 → 应用”中卸载 Mouse Combo，或运行安装目录中的 unins000.exe。标准卸载会删除程序、快捷方式、注册表项和 %APPDATA%\MouseCombo 数据。删除前请备份需要的宏。

安装程序的许可页提供“我接受 / 我不同意”；不同意并取消安装不会写入程序文件。软件内“使用说明 → 风险声明”中的“不同意并卸载”会调用标准卸载程序，删除程序、快捷方式和本机数据。源码运行模式不会删除源码文件。

4. 安全使用建议

  • 只使用你理解并信任的宏动作；不要加载来源不明的宏文件。
  • 运行前确认焦点窗口和鼠标位置正确；给停止热键留出空间。
  • 不要在无人值守、金融交易、医疗、交通、工业控制或生产环境中运行。
  • 长时间高频点击会加速鼠标微动、键盘轴体等硬件损耗。
  • 如果目标程序禁止自动化或合成输入，请停止使用，而不是绕过其安全机制。
  • 定期备份重要数据和宏文件；本程序不提供数据恢复服务。
