MOUSE COMBO · 1.5.2

Installation & Risk Statement

Version 1.5.2 · Installed edition · Read fully before use

Read before installing: This program simulates real mouse clicks and keystrokes and installs global keyboard/mouse hooks. It can cause unintended actions, data loss, account penalties, platform-rule violations or legal risk. Test in a safe environment and verify that your use is lawful.

1. Requirements

  • Windows 10 / Windows 11, 64-bit.
  • The installed edition does not require Python or a network connection.
  • The UI supports Chinese / Japanese / English. Use the language menu in the top-right; the window restarts and keeps the current macro.
  • The installed edition checks GitHub Releases at launch and installs updates silently by default. Disable this from the version menu in the top-right.
  • If the target application runs elevated, run Mouse Combo elevated as well. This does not bypass all of the target's protections.

2. Installation steps

  1. Obtain MouseCombo-Setup-1.5.2.exe from a trusted source and run it.
  2. Read the full guide and risk statement in the installer. Choose I accept to continue or I do not accept to exit.
  3. Choose the install location and Start Menu folder; the desktop shortcut is optional. The default is %LOCALAPPDATA%\Programs\MouseCombo.
  4. After installation, launch Mouse Combo from the Start Menu or desktop shortcut.
  5. On first run, set the hotkey (mouse side buttons 4/5 are supported) and trigger mode, then test the stop method with a safe single-step macro.
  6. In the left Macro library, enter a name and category and click Save. Click any list item to switch; no extra window is needed.
  7. If the target app runs elevated, also launch Mouse Combo as administrator.

Uninstall from Windows Settings → Apps, or run unins000.exe in the install directory. The standard uninstaller removes the program, shortcuts, registry entry and %APPDATA%\MouseCombo data. Back up any macros you need first.

The installer license page provides I accept / I do not accept. Declining and cancelling does not write program files. The in-app Help → Risk statement → Do not accept and uninstall invokes the standard uninstaller to remove the program, shortcuts and local data. Source-tree runs do not delete source files.

4. Safe-use recommendations

  • Only use macros you understand and trust; do not load macros from untrusted sources.
  • Check the focused window and cursor position before running; keep the stop hotkey accessible.
  • Do not run unattended, or in financial trading, medical, transportation, industrial control or production environments.
  • Long high-frequency clicking accelerates wear on mouse switches, keyboard switches and other hardware.
  • If the target app prohibits automation or synthetic input, stop using it rather than bypassing its protections.
  • Back up important data and macros regularly. This program does not provide data recovery.

5. Code signing and verification

MouseCombo.exe and MouseCombo-Setup-1.5.2.exe are signed with the project's self-signed code-signing certificate and carry a timestamp. The certificate is not issued by a public CA, so Windows may still show Unknown publisher or a SmartScreen warning on first run.
