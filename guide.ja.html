MOUSE COMBO · 1.5.6

インストールとリスク声明

バージョン 1.5.6 · インストール版 · 使用前に全文をお読みください

インストール前に必読: 本プログラムは実際のマウスクリックとキー入力をシミュレートし、グローバルなキーボード/マウスフックをインストールします。実際のアプリで誤操作、データ損失、アカウント制裁、プラットフォーム規約違反、法的リスクを引き起こす可能性があります。安全な環境でテストし、利用場面が合法であることを確認してください。

1. 動作要件

  • Windows 10 / Windows 11、64 ビット。
  • インストーラー版は Python のインストールもネット接続も不要です。
  • UI は 中文 / 日本語 / English に対応。右上の言語メニューで切り替えられ、自動再起動後も現在のマクロを保持します。
  • インストール版は起動後に GitHub Releases を確認し、既定でサイレント更新します。設定ページから無効にできます。
  • 設定ページではシステム連動 / ライト / ダークテーマ、内蔵フォントとシステムフォント、8～12 pt の文字サイズ、文字色、言語、更新を設定できます。
  • 対象アプリが管理者権限で動作している場合、本ツールも管理者として実行する必要があります。ただし対象アプリの保護をすべて回避できるわけではありません。

2. インストール手順

  1. 信頼できる配布元から MouseCombo-Setup-1.5.6.exe を取得し、実行します。
  2. インストーラーで本説明とリスク声明を全文読み、「同意する」で続行、「同意しない」で終了します。
  3. インストール先とスタートメニューのフォルダを選択。デスクトップショートカットは任意。既定は %LOCALAPPDATA%\Programs\MouseCombo。
  4. インストール完了後、スタートメニューまたはデスクトップから起動します。
  5. 初回はホットキー（マウスサイドボタン 4/5 対応）とトリガーを設定し、安全な単一ステップで停止方法を確認します。
  6. 左の「マクロライブラリ」で名前とカテゴリを入力して「保存」。一覧をクリックするだけで切り替えられます。
  7. 対象アプリが管理者権限で動作する場合は、Mouse Combo も管理者として起動してください。

インストーラー SHA256
F1B026310ACD42A970FD321FBF47E3E11B253C73750C06714C9B447393A67B64

Windows の「設定 → アプリ」で Mouse Combo をアンインストールするか、インストール先の unins000.exe を実行します。標準アンインストーラーはプログラム、ショートカット、レジストリ、%APPDATA%\MouseCombo のデータを削除します。必要なマクロは事前にバックアップしてください。

インストーラーのライセンスページには「同意する / 同意しない」があります。同意せずキャンセルした場合、プログラムファイルは書き込まれません。アプリ内の「使い方 → リスク声明 → 同意しない（アンインストール）」は標準アンインストーラーを呼び出し、プログラム、ショートカット、ローカルデータを削除します。ソース実行ではソースファイルを削除しません。

4. 安全な使用のための推奨

  • 内容を理解し、信頼できるマクロだけを使用してください。出所不明のマクロファイルを読み込まないでください。
  • 実行前にフォーカス中のウィンドウとマウス位置を確認し、停止ホットキーを押せる状態にしてください。
  • 無人環境、金融取引、医療、交通、産業制御、生産設備では実行しないでください。
  • 長時間の高頻度クリックは、マウスのマイクロスイッチやキースイッチの消耗を早めます。
  • 対象アプリが自動化や合成入力を禁止している場合は、安全機構を回避せず使用を中止してください。
  • 重要なデータとマクロを定期的にバックアップしてください。本プログラムはデータ復旧を提供しません。

5. コード署名と検証

メインの MouseCombo.exe とインストーラー MouseCombo-Setup-1.5.6.exe は、プロジェクトの自己署名コード証明書で署名され、タイムスタンプも付いています。公開 CA の証明書ではないため、初回起動時に「不明な発行元」や SmartScreen の警告が表示される場合があります。

SHA256: 9778EDB71B9D337AF1DAEAEEACB7B59F6A819C669BE7BCF0D5D874928DB9DCC7

公開証明書はインストーラーに同梱され、本サイトからもダウンロードできます。公式サイトの SHA256 を確認し、入手元を信頼できる場合に限り、現在のユーザーの「信頼されたルート証明機関」にインポートしてください。インポート後は Get-AuthenticodeSignature が Valid になります。

インストーラーが生成する unins000.exe は個別署名されません。証明書の秘密鍵はインストーラーにも本サイトにも含まれません。
